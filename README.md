# Forecast-Project-Electricity-Consumption-in-Metropolitan-France
Develop, evaluate, and review a comprehensive electricity demand forecasting chain for metropolitan France. The work must go beyond simply adjusting a model, it is necessary to define the problem, replicate a realistic operational scenario, compare several methods, and critically analyze the results obtained.

data used : 
- electricity demand éCO2mix, publiée par RTE
- weather observations from Météo-France's SYNOP network
- calendar variables from API: time, day of the week, month, weekends, holidays, vacations, or justified events
- football matches from API: French football team games and French championship
- past strike actions from API
